Ubuntu Core packaging, watchdogs, provenance. Alongside that I build Rust numerical engines and
CI/release infrastructure for [OptiLayer](https://www.optilayer.com) (thin-film optics software).
Earlier: electron-microscopy software for FEI (now Thermo Fisher), KDE desktop applications.
